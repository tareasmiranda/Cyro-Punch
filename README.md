## MirandaOrganizer(beta)
MirandaOrganizer es una app que esta pensada en el usuario común y en personas con TOC(organizadas) y que quieran una forma fácil y simple de administrar sus compras
semanales. Se diferencia de otras shopping list principalmente, en que esta basada 100% en las opiniones y necesidades de los usuarios.

## Instrucciones de instalación
Para usar la instalación desde el repositorio o portable, sigue estos pasos:
### Windows

1. Clona el repositorio ejecutando 
```git clone https://github.com/tareasmiranda/Cyro-punch.git```
```cd Cyro-punch```.
2. Crea un entorno virtual de Python ejecutando```python -m venv venv```.
3. Activa el entorno virtual ejecutando ```venv\Scripts\activate```.
4. Instala las dependencias ejecutando ```pip install --upgrade pip``` 
```pip install -r requirements.txt```.
5. Una vez instalado, puedes lanzar la aplicación con ```python main.py```.

### Linux

1. Clona el repositorio ejecutando ```git clone https://github.com/tareasmiranda/Cyro-punch.git;cd Cyro-punch```.
2. Crea un entorno virtual de Python ejecutando ```python3 -m venv venv```.
3. Activa el entorno virtual ejecutando ```source venv/bin/activate```.
4. Instala las dependencias ejecutando ```pip install --upgrade pip;pip install -r requirements.txt```.
5. Una vez instalado, puedes lanzar la aplicación con ```python main.py```.
